## 二、软件总体架构

本软件是一套基于深度学习的PCB（印制电路板）缺陷自动化检测与智能分拣系统，采用 YOLO11（You Only Look Once）目标检测算法，实现对PCB板上6类常见缺陷的实时识别，并驱动硬件执行自动分拣动作。

## 三、程序主要功能说明

### 3.1 检测模型推理（inference.py）

#### 3.1.1 PCBDefectDetector 检测器类

- **初始化**：`__init__(config, model_path, use_clahe)` 加载 PyTorch YOLO11 模型或 ONNX Runtime 模型
- **图像预处理**：`preprocess()` 支持 CLAHE（对比度受限自适应直方图均衡化）增强，提升PCB细微缺陷的可见性
- **缺陷检测**：`detect(image)` 返回包含 `detections`、`inference_time`、`fps`、`backend` 的字典
- **结果可视化**：`draw_results(image, results)` 在原图上绘制边界框、类别标签、置信度和FPS信息
- **批量检测**：`detect_batch(image_dir, save_dir)` 对目录中所有图片进行批量检测

#### 3.1.2 ONNXPCBDefectDetector 加速推理类

- 使用 ONNX Runtime 执行推理，支持 CPU/GPU 自动切换
- 实现 Letterbox 等比例缩放 + 填充的预处理
- 实现自定义 NMS（非极大值抑制）算法，避免重复检测框
- 模型预热功能：`warmup()` 减少首次推理延迟

#### 3.1.3 支持的缺陷类别（6类）

| 类别ID | 英文名称 | 中文名称 |
|--------|---------|---------|
| 0 | open | 开路 |
| 1 | short | 短路 |
| 2 | mousebite | 鼠咬 |
| 3 | spur | 毛刺 |
| 4 | copper | 杂铜 |
| 5 | pin-hole | 漏孔 |

### 3.2 主系统运行（main.py）

#### 3.2.1 PCBDefectSystem 主类

- **初始化**：`__init__(config_path, mock_hardware)` 加载配置、初始化各子系统
- **自动模式**：`run_auto_mode()` — 传送带运行→红外触发→采集→推理→分拣的闭环流程
- **手动模式**：`run_manual_mode()` — 空格触发单帧检测，键盘操作
- **演示模式**：`run_demo_mode()` — 对20张样本连续检测并生成评估报告

#### 3.2.2 自动模式工作流程

```
1. 传送带持续运行（motor_start）
2. 等待节拍间隔（time.sleep）
3. 停止传送带（motor_stop）
4. 摄像头采集图像（camera.read）
5. YOLO11模型推理（detector.detect）
6. 误报屏蔽过滤（suppressor.filter_detections）
7. 设备健康度记录（equipment_monitor.record_frame）
8. 声光报警（alarm_manager.trigger）
9. 绘制检测结果（draw_results）
10. 舵机分拣（controller.sort_pcb: OK→45° / NG→135°）
11. 追溯数据库写入（trace_db.add_record）
12. 重新启动传送带（motor_start）
13. 循环至步骤2
```

### 3.3 图形用户界面（ui/gui.py）

#### 3.3.1 主要界面功能

| 功能 | 描述 |
|------|------|
| **实时视频预览** | QLabel显示摄像头帧，支持检测结果叠加 |
| **检测结果表格** | 显示类别、置信度、位置坐标 |
| **专家评分模式** | 评委逐帧判分（正确/错误），统计准确率 |
| **统计仪表盘** | 合格率圆形进度条、缺陷类别柱状图、推理性能统计 |
| **设备健康度** | 光源/摄像头/推理状态的绿/黄/红三级显示 |
| **一键换线** | 下拉选择产线配置，自动更新检测阈值 |
| **误报屏蔽管理** | 添加/删除矩形屏蔽区域，支持命中次数统计 |
| **批量复核** | 批量标记误报/确认正确检出 |
| **SN码追溯** | 输入SN码查询历史检测记录 |
| **CSV报表导出** | 导出检测统计、缺陷分布、专家评分记录 |
| **生产报表** | 班次报表、7天缺陷趋势、操作员绩效 |
| **急停按钮** | 红色大字急停，一键停止传送带和舵机 |
| **摄像头重连** | 自动检测断开并重连（最多3次尝试） |

#### 3.3.2 CameraThread 摄像头线程

- 独立 QThread 子类，避免GUI阻塞
- 连续10帧读取失败时判定为断开，触发重连流程

#### 3.3.3 DetectionThread 检测线程

- 等待新帧信号（QWaitCondition），有帧才推理
- 结果通过 pyqtSignal 传递回主线程

### 3.4 硬件控制（utils/serial_control.py）

- 通过 RS232/USB 与 Arduino 通信
- 支持操作：电机启动/停止、舵机分拣（OK/NG角度）、急停
- 模拟模式（mock=True）：无Arduino时模拟响应

### 3.5 误报屏蔽（utils/false_alarm_suppressor.py）

- 支持矩形屏蔽规则（x1,y1,x2,y2）
- 每次检测命中后记录命中次数
- 支持按产线配置切换规则集

### 3.6 追溯数据库（utils/traceability.py）

- SQLite 数据库，记录字段：
  - product_sn（SN码）
  - operator_id（操作员工号）
  - equipment_id（设备编号）
  - line_profile（产线配置）
  - result（OK/NG）
  - num_defects（缺陷数量）
  - inference_time_ms（推理耗时）
  - image_path / result_image_path（图片路径）
  - defects（缺陷详情JSON）
  - review_status（复核状态）
  - reviewed_by（复核人）

### 3.7 报警管理（utils/alarm.py）

| 报警等级 | 触发条件 | 动作 |
|---------|---------|------|
| INFO | 正常检测到缺陷 | 短蜂鸣 |
| WARNING | 缺陷数 1-2 | 中等蜂鸣 + 黄色灯光 |
| CRITICAL | 缺陷数 ≥3 | 长蜂鸣 + 红色灯光 |

### 3.8 设备健康度监控（utils/equipment_monitor.py）

- **亮度检测**：平均像素值 < 40 → 异常 / 40-220 → 正常 / > 220 → 异常
- **帧率监控**：< 10fps → 注意
- **推理耗时**：> 200ms → 注意

## 四、数据流与接口说明

### 4.1 图像数据流

```
摄像头 (OpenCV VideoCapture)
    ↓ BGR格式 numpy数组 (H, W, 3)
YOLO11模型 (inference.py detect)
    ↓ 推理推理
检测结果字典 {
    'detections': [{'bbox': [x1,y1,x2,y2], 'confidence': float, 'class_id': int, 'class_name': str}, ...],
    'num_detections': int,
    'inference_time': float(ms),
    'fps': float,
    'backend': 'pytorch'|'onnx'
}
    ↓
绘制函数 (draw_results)
    ↓ BGR格式带标注图像
GUI显示 / 文件保存
```

### 4.2 配置文件接口（configs/config.yaml）

- 数据集配置（路径、类别）
- 模型配置（YOLO11n、置信度阈值0.25、IoU阈值0.45）
- 训练配置（20 epochs、batch=16、device=cpu）
- 硬件配置（摄像头分辨率1920×1080、Arduino COM3）
- GUI配置（窗口1400×900、30fps刷新）

## 七、技术特点

1. **YOLO11深度学习模型**：基于 Ultralytics YOLO11 目标检测算法，支持 PyTorch 和 ONNX Runtime 双后端推理
2. **CLAHE图像预处理**：对比度受限自适应直方图均衡化，提升PCB细微缺陷特征可见性
3. **误报屏蔽机制**：用户可定义矩形屏蔽区域，过滤固定误报区域
4. **一键换线**：产线配置热切换，无需重启系统即可适应不同PCB板型
5. **全流程追溯**：SN码 + 操作员 + 设备编号 + 检测图片的完整追溯链
6. **专家评分模式**：支持评委逐帧判分，统计模型准确率
7. **设备健康度监控**：实时监控光源/摄像头/推理性能异常
8. **多级声光报警**：根据缺陷数量触发不同级别的声光报警
9. **Arduino硬件控制**：通过串口协议控制传送带电机和分拣舵机
10. **多线程架构**：摄像头线程和检测线程并行，避免GUI阻塞
